# CR20KB «Калька Web» 0.1.0 preview

Изолированный проверочный вариант, **не готовый к полноценному выпуску**. Пользовательские файлы обрабатываются в браузере. Для сравнения нужна ручная проверка совмещения; результат не заменяет инженерную проверку.

## Первый просмотр

Из этого каталога с Node.js 24 выполните:

```powershell
node build.mjs
node serve.mjs
```

Откройте `http://127.0.0.1:4173/kalka-web/`. Сервер нужен только для локальной проверки разработчиком. Для конечных пользователей разместите содержимое `dist/` целиком на HTTPS в отдельном каталоге, например `https://example.org/kalka-web/`. Настройте MIME: `.mjs` и `.js` — JavaScript, `.wasm` — `application/wasm`, `.webmanifest` — `application/manifest+json`, `.html` — `text/html`; сохраняйте остальные файлы и каталоги. Не используйте открытие `index.html` двойным щелчком. После загрузки дождитесь индикатора готовности: он означает, что текущая страница контролируется Service Worker и обязательные ресурсы присутствуют в его кэше. Доступность установки зависит от браузера; вкладка работает без установки. После очистки хранилища для подготовки потребуется сеть. Обновление не принудительно перезагружает открытые страницы; для каждого нового выпуска меняйте имя кэша в `src/sw.js`.

Первые три действия: (1) откройте два чертежа и совместите их вручную; (2) нажмите «Сравнить A / B», изучите области и экспортируйте PNG; (3) сохраните проект локально, экспортируйте `.kalkaweb`, закройте вкладку и проверьте восстановление без сети. Состояние загрузки означает передачу браузеру, а не гарантию записи на диск. Важные проекты экспортируйте отдельно; постоянное хранилище браузера не гарантировано.

## Что реализовано и ограничения

- До 10 PDF/JPG/PNG; один слой — одна страница. PDF рендерится с 144 DPI, но снижается до 4 Мп; размер растра и приблизительный DPI показаны в параметрах. PNG/JPEG ограничен 8 Мп на файл, суммарный растр 24 Мп, композиция и сравнение 8 Мп. Исходники ограничены 40 МиБ на файл и 80 МиБ всего. Ограничения не являются измерением реального потребления памяти.
- Просмотр, сравнение и экспорт используют один и тот же растр; независимые разрешения пока не реализованы. На больших PDF мелкие правки могут исчезнуть после уменьшения. Часть операций PDF и Canvas выполняется в основном потоке; отмена относится к Worker, а не ко всем этапам. Нет полосы прогресса и автоматического совмещения. Коррекция сдвига из Windows backend не перенесена.
- Контуры областей строятся по разнице масок, как в `kalka_compare.py`: порог 56, объединение соседних компонентов; преобразования и состав визуального интерфейса адаптированы из `web/app.js`. Это самостоятельный перенос, не полный эквивалент Windows. После сравнения A отображается синим, B красным, общие штрихи фиолетовыми; обычное наложение видимых слоёв использует выбранные цвета и непрозрачность. Сдвиг или различия растрирования могут создать ложные области. Маркеры включаются отдельно.
- Данные исходников находятся внутри версии 1 JSON `.kalkaweb`; существующие Windows `.kalka` несовместимы. Формат ограничен по размеру, вход проверяется, исполняемый код и архивы не используются. Исходные файлы не изменяются.
- Пока не полностью локализованы сообщения исключений PDF.js и окно авторства; Chrome-снимок телефона является эмуляцией, не проверкой Android. Подробные результаты и выпускные блокеры — в `TEST_REPORT.md`.

## Проверки разработчика

```powershell
node --test tests/*.test.mjs
node build.mjs
$env:NODE_PATH = '<каталог с playwright и pdf-lib>'
node tests/browser.cjs
```

`tests/browser.cjs` использует Playwright 1.62.1, pdf-lib 1.17.1 и локальный Chrome; он запускает временный сервер только на loopback. Переменная `CHROME_PATH` позволяет указать Chrome. Проверка реальной пары `tests/real-pair.cjs` дополнительно использует sharp 0.35.5 и локальные пути исходников; личные файлы и результаты `test-output/` в Git не входят. Зависимости этих тестов не нужны конечному пользователю и не входят в dist; продуктовые runtime-ресурсы PDF.js 5.6.205 закреплены в `src/vendor/pdfjs`. `package-lock.json` фиксирует пакет сборки без npm-зависимостей.
