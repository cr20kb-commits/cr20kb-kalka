# Проверки Web 0.1.0 preview — 04.11.2026

Это предварительная сборка. PASS относится только к описанным примерам и средам, не ко всему заданию. Пользовательские чертежи, выгрузки и скриншоты хранятся локально в `test-output/` и не входят в Git или пакет.

## Окружение и команды

Windows, Node.js 24.22.1, Playwright 1.62.1, Chrome 156.0.8078.80, pdf-lib 1.17.1; для реальной пары также sharp 0.35.5. `node build.mjs`, `node --test tests/*.test.mjs`, `node tests/browser.cjs`, `node tests/real-pair.cjs`. Логи: `test-output/unit.log`, `test-output/browser.log`, `test-output/real-pair.log`. Для браузерных тестов `NODE_PATH` указывал на локально установленный набор библиотек, localhost разрешён отдельно. Скриншоты `test-output/desktop.png` и `test-output/mobile-emulated.png`: Chrome desktop и эмуляция размера экрана, соответственно.

`git diff --check` сообщает о конечных пробелах и пустой строке в исходных файлах лицензий PDF.js; они сохранены побайтно. Проверка изменений собственного кода без `src/vendor/` проходит.

## Результаты

- **PASS**: сборка статического пакета; изолированный scope `/kalka/`; контроль Service Worker и наличие ресурсов в кэше перед индикатором готовности.
- **PASS**: одна и та же PDF-страница дважды — 0 областей; PDF с двумя страницами, горизонтальная правка 70 → 71 и синтетическая вертикальная правка обнаружены. Тест проверяет фиолетовый общий штрих и белый фон по точным пикселям PNG.
- **PASS**: реальная пара `Петля конструктор.jpg` / `Петля технолог.jpg`, 3183 × 2250, A/B без сдвига и поворота, масштаб 1: две области. В экспортированном изображении есть оранжевые пиксели рамок в заранее определённых окрестностях правки у 50 (192 пикселя) и вертикального 70 → 71 (232). Проверка координат выполнена по исходникам, не по старым скриншотам. Чертежи не включены в Git. Общий результат: `test-output/real-pair-desktop.png`; экспорт: `test-output/real-pair-marked.png`.
- **PASS**: 10 синтетических слоёв PNG 640 × 480; геометрия поворота, прозрачность маски, отдельные добавленный и удалённый пиксель, контроль размеров заголовка изображения, проверка структуры и версии проекта.
- **PASS**: локальное IndexedDB, закрытие вкладки, отключение сети, открытие нового окна по прежнему адресу, восстановление проекта, новые локальные PDF/PNG, сравнение и скачивание PNG и проекта. Экспортированный проект повторно импортирован; проверены страница 2 и побайтовое совпадение исходного PDF в экспорте.
- **PASS, ограниченный аудит сети**: в тестовом контексте Playwright зафиксированы только GET к собственному локальному URL и data URL; POST и внешних запросов нет. Результат относится к проверенному сценарию; сервер логов содержимого пользовательских файлов не ведёт.
- **FAIL относительно полного задания**: автоматическая компенсация общего сдвига 1–2 px из Windows-алгоритма отсутствует. Синтетический сдвиг показывает различия, а не выполняет автосовмещение. Нет независимых разрешений просмотра, сравнения и экспорта, настройки DPI, потокового экспорта и полной отмены PDF-растеризации. Ошибки PDF.js и окно авторства локализованы не полностью. На больших PDF возможна потеря тонких деталей из-за ограничения 4 Мп; использовать как приёмочное сравнение таких чертежей нельзя.
- **NOT RUN**: пригодность на большом инженерном PDF/A0, устойчивость JPEG и различных растеризаций за пределами одного синтетического порога, защищённый и повреждённый PDF, реальный отказ/квота IndexedDB, обновление установленной PWA с несохранённым проектом, измерение потребления памяти, тест маркеров при ручном панорамировании и проверка после очистки хранилища. Слабая разница масок ниже 56 сознательно не отмечается; тест проверяет пример разностей 35 и 75, не устанавливая общей устойчивости.

Ручной чек-лист для каждой недоступной среды: открыть HTTPS-адрес и дождаться готовности; при наличии штатного пункта установить приложение; закрыть все вкладки, отключить сеть и заново открыть адрес/ярлык; восстановить проект, открыть новый PDF и PNG, сравнить, выгрузить оба формата и повторно открыть проект. На телефоне проверить поворот экрана, жесты и читаемость. После окончания проверки вернуть сеть. Критичные данные предварительно сохранить в отдельный проектный файл.
